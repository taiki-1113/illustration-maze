# クリア時の花火

ユーザー承認案: approved-concept.png。レトロな紙のカードと朱色のクリア印を維持し、金・朱色・青緑の花火を周囲に配置します。新しいコピーや絵文字、音声は追加しません。

実装は dist/fireworks.js と dist/celebration.js、アニメーションは dist/style.css。画像生成したモックアップは制作資料のみで、ゲームには配信しません。

- 最大5発。左右の大輪2つ、下側の小輪2つ、上部の小輪1つ。余白に合わせてサイズ・個数を減らします。狭い画面では上下へ配置。
- 花火の形は3種類の320px SVG画像を再利用。44本の曲線を少数のパスにまとめ、静止したままHTML側の拡大・移動・透明度だけをアニメーション。
- 打ち上げはカードの外側の列のみ。カードの上へ火花や軌跡を通さず、全レイヤーはpointer-events:none。
- 最大344pxの表示サイズ、最大8枚の金色の紙片。花火は遅延0.38〜1.28秒、開花から消失まで2.65秒、全体4.6秒で片付け。
- カードを閉じる・再生し直す・画面回転・タブを隠す時に、レイヤーと唯一のタイマーを削除。
- 動きを減らす設定では花火・紙片・タイマーを作りません。ボタンは演出を待たずに操作できます。

確認: 75テスト。カードとの非重複は落下・拡大後の外接矩形でも検証。ブラウザで横1280×800、縦800×1280、低い画面1280×480を確認。実際のAndroid端末のFPSは未計測。
