# 一覧用サムネイルの原本

完成済み10作品の一覧SVGを、変更前の実画面DOMから保存した固定スナップショットです。プレイ中のSVGや当たり判定には使用しません。サムネイル用に迷路を生成・複製する処理を利用端末で走らせないための制作時入力です。

- 再生成: `npm ci` → `npm run build:previews`
- 出力: `dist/assets/previews/*.webp`（幅640px）、`dist/assets/home-rocket.webp`（幅600px）
- 元の挿絵PNG、SVGの形・座標・プレイ用の高解像度画像は維持しています。
- SVG内の画像参照は制作時に読み込み、WebPへ焼き込みます。利用端末がサムネイルのために元の大きいPNGを開くことはありません。
- 見た目を変更した場合は、未プレイの状態のSVGスナップショットも更新してから再生成してください。大きいSVGの書き出しは文字列が切れないよう分割して保存しました。
- Zen Maru Gothic Black はGoogle Fonts公式配布のものです。文字の形を合わせる制作時だけに使い、WebページではこのTTFを配信しません。同梱のOFL.txtを参照。
- 画像処理ライブラリは開発用依存です。GitHub Pagesへ配信するのは生成済み画像のみです。
