# イラストめいろ

公開先: https://taiki-1113.github.io/illustration-maze/

レトロな紙の質感と枠装飾を使った一覧画面と、画面いっぱいで遊べるプレイ画面。15作品を収録。

要件.txt と参考画像をもとに、単体モチーフ5作品、広い迷路5作品に、にわとり相当の難度の冒険迷路5作品を追加しました。

## ローカル起動

Node.js 20 以上で、このフォルダ内から実行します。依存パッケージのインストールは不要です。

```sh
npm start
```

ブラウザで http://127.0.0.1:4187 を開きます。終了は Ctrl+C。

## あそびかた

- 一覧から作品を選び、スタートの丸（宇宙探検はロケット）を押したまま通路をなぞります。
- 壁に当たると止まります。指を離したら、色のついた先端から再開できます。
- 通った道を戻ると軌跡が戻ります。「やりなおす」で初期状態になります。
- ゴール（宇宙探検では基地の入口）に到達するとクリアです。クリア状況を端末内に記録します。
- マウスでも遊べます。迷路にフォーカスし Enter、続いて矢印キーでも操作できます。

## 実装

- 外部ライブラリ不要の HTML / CSS / JavaScript と SVG。
- カタツムリ・カメは5層・104区画の円形グラフ、さかなは394区画の格子グラフを生成。固定 seed で同じ迷路を再現。
- 描画と当たり判定が同じ壁データを使用。ポインター移動は 2 SVG px 以下に分割し、壁のすり抜けを防止。
- 開始・ゴール・正解経路を迷路データから取得。
- PWA manifest と Service Worker を実装。初回の基本データ保存後、同一端末でオフライン起動できます。元の作品画像は一覧表示後にバックグラウンド保存するため、すべての作品をオフラインで開くにはその保存完了が必要です。配信には HTTPS または localhost が必要です。
- 途中の軌跡は画面内のみ保持。ページ再読み込み後は開始地点に戻ります。クリア状況は localStorage に保存。
- 作品選択から15作品を自由に選択できます。クリア後は「つぎの めいろへ」で切り替えられます。
- 作品間を移動してもページを開いている間はそれぞれの途中経過が残ります。クリア記録は作品ごとに保存します。
- `#home` が一覧です。`#snail` / `#turtle` / `#fish` / `#owl` / `#rocket` / `#family` / `#garden` / `#sea` / `#picnic` / `#space` で各作品を直接開けます。
- カタツムリの経路は基準版から変更していません。カメは別の固定 seed と生成設定で分岐を増やしています。予定していた宇宙探検を加え、全10作品がそろいました。

## 高難度のさかな

- 独自に生成した魚形の格子迷路。参考資料の画像や経路を流用していません。
- 固定 seed 1、394区画、正解114移動、正解上の分岐18か所、行き止まり59か所。
- 参考の魚（330区画・112ステップ・行き止まり59）に近い規模を狙っています。実際の難しさが同じであることを保証するものではありません。
- 1本指でなぞり、下部のボタンで拡大縮小・表示位置の移動を操作します。
- やりなおし時は、拡大率を維持してスタートを画面内に戻します。
- 初期のカタツムリ・カメの迷路構造はそのままです。

## UIとGitHub Pages公開

- 一覧は独立したトップ画面。作品カード全体から開始でき、クリア状況を表示します。
- プレイは上部の戻るリンク・作品名と、下部の小さな操作列を表示。ボタンは迷路に重なりません。
- ビューポートと作品の縦横比から、全体が収まる最大サイズを計算。縦長スマートフォンでは細かい格子迷路を初期拡大し、スタートを表示します。「全体」ボタンで全体表示に戻せます。
- 全15作品を最大300%まで拡大できます。拡大中も1本指でなぞり、矢印ボタンで表示を移動できます。
- ブラウザの戻る・進むと作品別URLに対応。キーボード操作では先端が画面から外れないよう表示を追従します。
- トップの透過ロケット画像は組み込み image_gen で制作。制作記録: art-direction/home-rocket-prompt.md。
- `.github/workflows/pages.yml` が `main` の更新時にテストを実行し、`dist/` だけをGitHub Pagesへ配信します。
- 相対URL、manifestの相対scope/start_url、相対パスのService Workerを使い、リポジトリ配下で動作します。
- 公開先の保存データは旧Sitesやlocalhostと別です。クリア記録は公開先のブラウザで新規に記録されます。

## ボタンでの表示操作（2026-11-21）

- 1本指・マウスは現在の先端から道をなぞります。2本指で拡大・移動はできません。
- 2本目の指が触れた時は描画を中断。全ての指を離してから再開します。
- ＋／−は100・150・200・250・300%の段階式。「全体」で100%に戻します。拡大時には先端を表示します。
- 4方向の矢印は1回で100px移動。長押しするとフレーム単位で移動し、離す・端に達する・画面を切り替えると停止します。
- ホイールとトラックパッドでも表示は動きません。キーボードの＋／−は引き続き利用できます。
- 制御: dist/board-navigation.js（なぞりのみ）、dist/board-controls.js（表示操作）。

## Androidタブレット向け・2作品の表示調整

- フクロウをportrait、宇宙をlandscapeに設定。ほかの作品の向き設定は維持。
- Androidでは一覧の作品選択または「つぎのめいろ」のクリックから全画面表示を要求し、その後に向き固定を試みます。
- 一覧へ戻る、ほかの対象外作品へ移る、利用者が全画面表示を閉じると、取得した向き固定を解除します。
- 拒否・非対応の場合も通常表示で遊べます。Androidで向きが合わない場合のみ短い案内を表示。
- URLを直接開いた場合は、利用者の操作なしに全画面表示を強制しません。自動固定を試すには一覧から対象作品を選択してください。
- 2作品は外枠をSVGの端へ移し、宇宙の周囲を濃紺、フクロウの周囲を紙色に統一。SVGのviewBox・絵・経路は変更せず、全体が収まる倍率で開始します。
- 制御は dist/play-orientation.js。Android実機の自動回転・全画面表示は未確認です。

## 一覧の軽量化

- 一覧ではプレイ用の迷路を生成せず、固定の軽量WebPサムネイルを表示します。作品を選択した時だけ迷路を生成します。
- 一覧へ戻るとプレイ用SVGを解放し、途中の軌跡は従来どおり保持。
- 初期キャッシュは基本ファイルと一覧画像を優先し、大きい作品画像はアイドル時に保存します。
- 一覧用画像の再生成は `npm ci` の後に `npm run build:previews`。通常のローカル起動・テスト・配信には画像処理ライブラリは不要です。
- 原本とフォントライセンス: art-direction/thumbnail-sources/。比較計測: PERFORMANCE.md。

## クリア時の演出

- クリアした作品の画像と作品番号を、紙の完了カードに表示。朱色の「クリア」スタンプを一度だけ押す演出です。
- 紙片32個の短い紙吹雪をCSSで表示し、3.3秒以内、またはカードを閉じた時に解放します。操作を待たせる時間は設けていません。
- 絵文字、王冠、定型の励まし文、音声、繰り返しアニメーションは使用しません。
- prefers-reduced-motionでは紙吹雪を生成せず、CSSアニメーションも止めて静かな完了カードを表示します。
- カードの画像は軽量サムネイルを再利用。一覧表示時には紙吹雪の描画要素を生成しません。
